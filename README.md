# 📊 Análise de Dados Educacionais — Regressão Linear

## 📌 Sobre o Projeto

Este projeto tem como objetivo analisar a relação entre as horas dedicadas aos estudos e o desempenho acadêmico dos estudantes, utilizando técnicas de análise exploratória de dados, visualização gráfica e regressão linear.

A análise foi realizada com a base de dados student_exam_scores.csv, contendo *200 registros de estudantes*, incluindo informações sobre:

- Horas de estudo;
- Horas de sono;
- Frequência escolar;
- Notas anteriores;
- Notas obtidas nas provas.

O projeto foi desenvolvido em duas etapas principais: análise gráfica no *LibreOffice Calc* e modelagem estatística no *Google Colab*, utilizando Python.

---

## 🛠️ Ferramentas e Tecnologias

| Ferramenta | Aplicação |
|---|---|
| LibreOffice Calc | Tratamento de dados e gráficos |
| Google Colab | Ambiente de execução Python |
| Python | Programação e análise estatística |
| Pandas | Manipulação e limpeza dos dados |
| NumPy | Operações numéricas |
| Matplotlib | Visualização gráfica |
| Scikit-learn | Regressão linear e avaliação do modelo |
| GitHub | Documentação e versionamento |

---

## 📈 Etapa 1 — Análise no LibreOffice Calc

Inicialmente, a base de dados foi importada para o LibreOffice Calc, software de planilhas eletrônicas compatível com arquivos do Microsoft Excel.

Durante o tratamento, foram verificadas as colunas numéricas e corrigidos problemas de interpretação dos separadores decimais.

Após a organização dos dados, foi desenvolvido um *gráfico de dispersão (XY)* para analisar a relação entre duas variáveis:

- *Eixo X:* Horas de estudo (hours_studied).
- *Eixo Y:* Nota da prova (exam_score).

Foi adicionada uma linha de tendência linear e exibido o coeficiente de determinação (R²).

O gráfico permitiu identificar uma tendência crescente, indicando uma associação positiva entre o tempo de estudo e o desempenho acadêmico.

---

## 🐍 Etapa 2 — Regressão Linear no Google Colab

Na segunda etapa, os dados foram importados para o Google Colab, ambiente de desenvolvimento que permite executar códigos Python diretamente pelo navegador.

### Preparação dos Dados

Foram realizadas as seguintes operações:

1. Importação da base de dados CSV.
2. Identificação dos tipos de dados.
3. Conversão das colunas numéricas.
4. Correção dos separadores decimais.
5. Verificação e remoção de registros inválidos nas variáveis analisadas.
6. Definição das variáveis independentes e dependentes.

Após o tratamento, foram utilizados *200 registros válidos*.

### Construção do Modelo

Foi aplicado um modelo de *regressão linear simples*, utilizando a biblioteca Scikit-learn.

O objetivo foi estimar a relação matemática entre as horas de estudo e as notas dos estudantes.

Também foram calculados indicadores estatísticos para avaliar a relação entre as variáveis e o ajuste do modelo.

---

## 📊 Resultados Obtidos

| Indicador | Resultado |
|---|---:|
| Registros analisados | 200 |
| Coeficiente de determinação (R²) | 0,6033 |
| Correlação de Pearson | 0,7768 |
| Erro quadrático médio (MSE) | 18,1937 |
| Coeficiente angular | 1,6341 |
| Intercepto | 23,6184 |

### Equação da Regressão Linear

A equação obtida foi:

text
Nota prevista = 23,6184 + 1,6341 × Horas de Estudo


O coeficiente angular indica que cada hora adicional de estudo está associada a um aumento médio estimado de aproximadamente *1,63 ponto na nota*.

### Interpretação Estatística

*R² = 0,6033*

O modelo explica aproximadamente *60,33% da variação observada nas notas*, considerando as horas de estudo como variável explicativa.

*Correlação de Pearson = 0,7768*

Indica uma correlação positiva relativamente forte entre as horas de estudo e as notas obtidas.

*MSE = 18,1937*

Representa a média dos erros de previsão elevados ao quadrado, permitindo avaliar o ajuste do modelo aos dados analisados.

Os resultados indicam uma associação estatística, mas não comprovam, isoladamente, uma relação de causalidade.
